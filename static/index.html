Pasos para obtener el certificado en AFIP

  1. Ingresar al portal de AFIP / ARCA:

    Acceda a auth.afip.gob.ar con Clave Fiscal Nivel 3 o superior.

  2. Entrar al servicio WSASS:

    Busque en los servicios habilitados: "Administración de Certificados Digitales" o "WSASS (Autogestión Servicios Web)".

  3. Crear Alias y Subir el CSR:

    Indique un nombre de alias (ej: facturador_cli) y pegue el contenido del CSR generado o suba el archivo .csr.

  4. Descargar el Certificado (.crt):

    Descargue el archivo de certificado y guárdelo en la carpeta certs/ de este proyecto.

  5. Asociar el servicio WSFE:

    En el "Administrador de Relaciones de Clave Fiscal", vincule el servicio Facturación Electrónica (WSFEv1) con el alias del certificado creado.
